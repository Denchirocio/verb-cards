# Verbos · Cards

App para practicar conjugación de verbos japoneses con flashcards, pensada para usar desde la tablet.

Menú → elegís la forma que querés estudiar (diccionario, ない, ます, て/た, ている) → cards que se voltean con el verbo en diccionario de un lado y la conjugación + la regla que la produjo del otro. Desde cualquier pantalla podés abrir la lista completa de verbos.

Los datos de verbos y la lógica de conjugación se reutilizan de [kanji-flashcards](https://github.com/Denchirocio/kanji-flashcards) (Denchi no Nihongo).

## Stack

Vite + React + TypeScript + Tailwind CSS v4.

## Desarrollo

```bash
npm install
npm run dev
```
